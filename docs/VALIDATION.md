# 细砂版本验证记录

2026-10-29。此记录对应细砂、细颈、惯性与无回弹接触版本，并包含翻转时逐层下落的修复。

## 这次改了什么

- 粒径从 4.4 改为 **1.3** 个模拟单位，默认数量从 1200 增加到 **10000**，保持接近原先的装砂面积。
- 窄口宽度从 28 改为 **5.2**，短颈由 ±12 缩短至 ±4。砂流集中在窄口下方，缓慢流出。
- 用无弹性的颗粒网格替代弹簧接触。粒子在空中有连续位置与速度，沿运动路径分段检查空格，避免高速穿过其他砂粒或玻璃。碰撞耗散动能；表面颗粒按重力方向与有效摩擦限制滚落。
- 落定后没有弹性储能，整个砂堆真正静止时停止更新。累计的重力变化超过 2 个加速度单位（约 0.003g）会唤醒砂堆；小幅、缓慢倾斜不会因为逐帧比较而丢失唤醒。
- 设备的含重力加速度同时提供倾斜与摇晃输入。它不会被归一化成恒定重力，也不会在下一次传感器读数到来时覆盖砂粒已有速度。运动限制为 4g，后台或过期读数归零。
- 绘制使用细小纹理与稳定的颜色分布，空中颗粒的短拖影由实际速度产生，落定时没有拖影或装饰性晃动。

## 完整流动与静止

默认一万粒，固定 120 Hz，推进 600 秒模拟：

| 指标 | 本次结果 |
| --- | --- |
| 30 秒时上腔余量 | 8669 粒 |
| 120 秒时上腔余量 | 4634 粒 |
| 210 秒时上腔余量 | 588 粒 |
| 240 秒时上腔余量 | 0 粒 |
| 首次完全落定 | 244.83 秒 |
| 左右表面休止角 | 33.22° / 33.32° |
| 落定后继续静置 5 秒，最大位移 | **0** |
| 越界粒子 | **0** |

这组初始状态约四分钟流完，不是固定时长承诺。改变姿态、摇晃或设备速度都会改变过程。完整数据见 [benchmark.json](benchmark.json)。

坡面测量在下腔中心两侧水平距离 20–75 的区域，每隔 5 单位采样，取附近半宽 3 单位内最高一粒砂的中心，线性拟合坡角。它测的是休止角，没有对实际砂材的首次雪崩临界角做标定。

## 回归检查

`npm test` 包含以下可重复检查：

- 默认一万粒的细砂与细颈尺寸、持续缓慢出砂，防止重新变成几秒流完的大开口。
- 2400 粒完整流完后形成约 32.7–33.0° 的砂堆，进入静止状态；再推进 5 秒，整个位置快照逐项完全相同。
- 对静止砂堆施加交替横向和竖向摇晃输入，确认会唤醒和移动；之后倒置，确认砂能全部重新流过窄口。
- 侧向和较强加速度下的粒子数量、格子占用、位置索引与玻璃边界一致。
- 空中粒子受 0.1 秒加速度脉冲后，停止脉冲的下一步仍保留超过 98% 的横向速度。
- 横竖屏、传感器极性、自由落体零读数、平移摇晃与限幅的坐标映射。

## 翻转后的整团自由落体

旧代码按粒子编号正序、倒序交替推进，后方砂粒会把本步尚未更新的前方砂粒当作固定支撑，误判碰撞并清零速度。160 粒悬空密排砂团在 0.17 秒后出现约 6 个模拟单位的内部位移差。

现在先根据重力与已有惯性确定整团运动方向，快照记录从前到后的占位顺序，再逐粒推进。前方砂粒在同一步内腾出格子，后方砂粒即可继续自由落体；快照避免移动后的粒子被重复更新。没有增加强制下落、速度补偿或冻结规则。

新增回归检查覆盖上下左右、四个斜向和与重力相反的已有惯性，分别使用正序、倒序和打乱的粒子编号。每一步都与独立空中粒子的位移、速度比较，误差小于 1e-8。另将实际落定的砂堆翻转，中心区域 557 粒砂在最初 0.2 秒内同步下落，位移约 13.21 单位，速度约 125.37 单位/秒。

## 模型范围

这是为细砂观感与把玩设计的颗粒网格模型，优先保证稳定堆积、无回弹和空中惯性。它没有求解理想圆盘的自转、弹性碰撞或气固耦合；有效摩擦、窄颈耗散和网格允许的滚落方向是近似。休止角受网格方向影响，不能将结果当作实验材料参数。

尚未在实体 Android / iPhone 上检查持续帧率、发热、功耗和运动传感器极性。所有测试的手机视口都来自桌面浏览器模拟。
