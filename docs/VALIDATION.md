# 验证记录

2026-10-29。以下是本仓库实际运行的结果，不是手机实测承诺。

## 沙堆与流动

默认 1200 粒，固定物理步长 1/480 秒，长度为模拟单位。法向弹簧、碰撞阻尼、切向接触位移历史与库仑摩擦共同决定运动。粒间有效摩擦系数 0.42，玻璃壁 0.12。没有规定表面必须维持某个角度，也没有低速冻结或强行放砂。

从上腔自然落砂，推进 30 秒后，左右自由表面相对水平的拟合角度为 **28.18° / 31.79°**。这次初始状态在 10 秒内流完，30 秒时 RMS 速度约 0.096 模拟单位/秒。测试另在 35 秒时测得 **28.17° / 31.79°**；翻转后再次完整流回上腔，侧向和强加速度检查均未发现越界或非有限状态。

测量方法：在中心两侧水平距离 20–75 的区域，每隔 5 单位采样，取该位置附近半宽 3 单位内最高一粒砂的中心高度，线性回归，再计算坡面角度。方法见 `scripts/benchmark.js` 的 `surfaceAngles`。它测的是自然落砂后的静止坡面（休止角），不是所有材料的普适角度，也没有测定加载过程中首次雪崩的临界角。

这是一种有效颗粒模型：圆粒不求解自转，摩擦代表粗糙颗粒的整体阻力；没有空气耦合和真实砂材标定。软接触允许重叠，30 秒检查的最大局部重叠为粒径的 **18.3%**。高速撞击玻璃时另有内侧边界保护，防止穿过零厚度壁面。它适合互动把玩，不用于工程计算或精确计时。

`npm test` 检查逐步过颈、流完、自然堆角、压缩上限、反向流动、侧向与强加速度下的容器边界、重置以及传感器坐标映射。改变摩擦、步长或容器后，应重新跑测试与 benchmark，而不是仅检查截图。

## 性能

环境：Linux、Intel Core Ultra 7 265K、Node.js 24.9.0、桌面 Chrome 无头模式。完整原始记录：[物理](benchmark.json)、[浏览器](browser-performance.json)。

| 检查 | 结果 |
| --- | --- |
| 物理步耗时中位数 / P95 | 0.300 / 0.343 ms |
| 每模拟 1 秒的 CPU 计算时间 | 约 146 ms |
| 390×844、DPR 2 浏览器绘制 | 60 FPS |
| 浏览器运行 10 秒的物理推进 | 约 9.9 秒 |
| Pages 构建产物 | HTML、CSS、主线程 JS、Worker JS 合计约 21 KB（未压缩，不含图标） |

浏览器脚本也执行了 4 倍页面 CPU 节流；这是页面目标的 CDP 节流，**不保证 Worker 同样受限**，不能把结果当作低端手机的物理性能。画面 FPS 与物理推进时间分开记录，避免画面流畅却模拟慢放而没有发现。Worker 追赶积压最多 12 个物理步；设备忙时会减慢模拟，不降低固定步精度、不删除沙粒。

尚未在实体 Android / iPhone 上验证持续帧率、发热、功耗与各浏览器的传感器极性。未实现静态沙堆休眠，后台页面会停止物理计算。

## 浏览器交互

`npm run test:browser` 已检查：

- 320×568、390×844、768×1024、1024×768、1440×900、844×390 的布局；无水平溢出，翻转按钮在视口内。
- 暂停后物理时间保持不变、继续、翻转、设置、换色与沉浸模式进入/退出。
- 模拟授权成功、拒绝、有效读数和读数中断；无页面异常。

截图来自实际运行页面：[手机](mobile.png)、[桌面](desktop.png)。浏览器模拟不能验证实体触摸手感、系统权限弹窗与熄屏行为。
