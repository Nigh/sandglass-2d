# 耦合接触与移动端验证

2026-10-29。记录对应连续空间颗粒、累计接触冲量、本地 WebAssembly 内核、移动端自动传感器和薄容器壁面摩擦版本。

## 模拟方法

旧模型按粒子占用格子决定能不能移动。即使改变遍历顺序，几次翻转后不同的速度和小数位置仍可能让运动中的邻居充当固定支撑；格子也没有传递接触压力的机制，漏斗两侧容易停住。

现在每一步分为：

1. 对所有砂粒同时施加输入加速度、空气阻力和前后壁面摩擦，预测所有位置。
2. 用运动路径的包围盒寻找候选接触，再检查相对轨迹。空间网格只加速搜索，一个格子可以有多粒砂，没有占位锁。
3. 对接触网络迭代求累计法向和库仑摩擦冲量，保存稳定接触的冲量以便下一步热启动。粒间响应使用相对速度，内部冲量成对抵消，不能把悬空整团的总动量凭空抹掉。
4. 用解出的真实速度统一更新位置，再独立修正残余穿透。位置修正不转换成反弹速度。

接触松弛从实际接触到玻璃的支撑网络向外传播；这只是接触方程的求解顺序，不是按运动方向逐粒移动。没有静态支撑的砂团不会因此得到固定支撑。集中撞击时使用更小的子步，热启动冲量按子步长度缩放。

方法参考 [Box2D Solver2D 的累计冲量与 PGS/NGS](https://box2d.org/posts/2024/02/solver2d/)、[Small Steps in Physics Simulation](https://matthias-research.github.io/pages/publications/smallsteps.pdf)。研究中也对照了 [颗粒位置摩擦](https://mmacklin.com/uppfrta_preprint.pdf) 和 [连续介质沙流](https://www.cs.ubc.ca/~rbridson/docs/zhu-siggraph05-sandfluid.pdf)；本实现没有照搬后两者的完整求解器。

## 手机平放与授权

设备含重力加速度按屏幕方向映射，保留大小，不归一化成恒定重力。垂直屏幕的分量绝对值用来估计极薄容器前后壁面的压力。

- 壁面静摩擦系数为 0.45，滑动摩擦系数为 0.35。平放时，前后壁面能制动惯性并平衡小幅平面加速度；倾角或摇晃超过摩擦限制后会继续滑动。
- 真正的三轴零读数仍代表零比力，不伪造壁面压力。三轴输入总幅值限制为 4g。
- 移动端打开页面即尝试传感器。浏览器需要瞬时用户手势时，显示「点击授权手机传感器」；授权后接管。手动切换后不会被后续读数擅自切回。
- 读数过期或页面离开前台会清除输入；后台停止模拟。

平台约束见 [MDN requestPermission](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static)。自动尝试不能越过浏览器要求的点击授权。

## 回归检查

`npm test` 的七项检查覆盖：

- 一万粒默认砂中，初始颈口两侧区域的砂在 8 秒后向内补位或穿过窄口，左右检查比例均为 **100%**。
- 一团具有不均匀初速度、真实互相接触的悬空砂，连续反向 12 次。逐步比较总动量与质心，和同样输入下的独立自由粒子误差分别小于 1e-7 和 1e-6，防止逐层损失运动。
- 2400 粒连续三个完整漏砂/翻转周期，每次落定后继续推进，位置快照完全不变；插入摇晃、横向和较强加速度后仍保持粒子数量、有限状态和玻璃边界。
- 短促加速度释放后继续保留空中惯性。
- 平放壁面压力能停止运动并保持小幅倾斜；三轴零输入下仍保留惯性；超过静摩擦限制后恢复滑动。
- 横竖屏坐标、极性、自由落体零读数、摇晃幅值和三轴限幅。

## 默认流动与性能

完整原始结果：[600 秒模拟](benchmark.json)、[浏览器](browser-performance.json)。环境为 Linux、Intel Core Ultra 7 265K、Node.js 24.9.0；手机视口使用桌面 Chrome 模拟。

默认一万粒，粒径 1.3 模拟单位。接触模型下将颈宽重新标定为 8 单位，约六粒宽，减少离散粗化颗粒的堵口；仍保持细颈和集中落砂。基本物理步频为 120 Hz，撞击时自适应细分。

本次完全落定约在 139 秒，左右表面拟合角度约 **34.8° / 38.9°**；落定后继续 5 秒最大位移为 **0**，没有越界。默认状态最后有 18 粒留在上腔；模型仍可能形成少量颗粒架桥，改变姿态或摇晃可以继续流动。它不是保证某个时长或每次都自动排空的计时器。

活跃外步耗时中位数约 11.8 ms、P95 约 13.0 ms，每模拟 1 秒约需 1.43 秒 CPU 时间。该数值包含自适应子步。浏览器手机布局绘制约 60 FPS，实际运行 10 秒推进约 6.9 秒物理时间。页面目标四倍 CPU 节流时约 37 FPS，但该节流不保证同样影响 Worker。分别记录画面与物理时间，避免把流畅绘制当作物理实时。

接触求解比旧占位规则更重。设备跟不上时会慢放，不删砂；完整落定后跳过计算。新内核约 13 KB（未压缩），源码为 [native/sand.cpp](../native/sand.cpp)，工作流从源码重新编译后测试。

`npm run test:browser` 覆盖移动端自动传感器、手势授权、拒绝、过期读数、平放模式，以及手机/平板/桌面/横屏布局、暂停、翻转、换色和沉浸模式。截图来自生产构建：[手机](mobile.png)、[桌面](desktop.png)。

尚未在实体 Android/iPhone 上验证持续帧率、发热、极性与实际摇晃手感。颗粒按无自转的粗糙材料点近似，前后壁面压力也是准二维近似；没有做真实砂材标定，休止角不等于实验室测得的雪崩临界角。
