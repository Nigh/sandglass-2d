# 流砂 · Sandglass 2D

一只可以随手翻转的二维沙漏。让砂慢慢落下，堆成小山，再翻过来玩一次。

**[打开沙漏](https://nigh.github.io/sandglass-2d/)** · 免费，无需登录，手机和电脑都能玩。

<img src="docs/mobile.png" alt="手机上的流砂：暖金色沙粒穿过窄口，在底部自然堆积" width="320">

## 怎么玩

- **拖动**沙漏来倾斜，**双击**画面或点「翻转沙漏」把它倒过来。
- **手机打开后默认使用传感器。** 如果浏览器要求授权，点「点击授权手机传感器」并允许。竖着握住手机，慢慢转动或轻轻摇晃，看砂散开后重新堆积。
- **平放手机，砂会被前后壁面的摩擦稳住。** 倾斜到足够角度或摇晃后才会滑动；这是一只很扁的容器，平放不等于失重。
- 点 **Ⅱ** 暂停，再点一次继续。右下角的 **⛶** 进入沉浸模式，点「退出沉浸」返回。浏览器允许时会全屏并保持屏幕常亮。
- 右上角 **☰** 可以换砂的颜色、调整传感器方向或重新装砂。
- 电脑上也能用 **← →** 倾斜、**F** 翻转、**空格**暂停。

没有传感器、不想授权，直接拖动就可以。传感器模式下拖动或点翻转会回到手动模式。翻转保留现有沙粒；「重新装砂」才会恢复起始分布。

## 没有反应，或者方向反了？

请在 Safari 或 Chrome 中直接打开上面的 HTTPS 链接，再尝试授权。部分内置浏览器不提供运动传感器。竖直握住手机时，如果砂往上走，在设置里切换「传感器方向反了」。

读数中断时会显示提示并将重力归零，恢复读数后继续。也可以点「回到手动把玩」。切到后台会暂停计算，回来后不快进补算。所有模拟和传感器数据都留在本机，没有账号、统计或数据上传。

## 这个版本有什么不同

它是 [三维流砂](https://github.com/Nigh/sandglass) 的独立重写。现在使用 **一万粒细砂**，砂粒在连续空间中运动，细颈让砂集中落下；已有速度不会在下次手机读数到来时被抹掉。

每一步先预测所有砂粒的运动，再统一解接触与摩擦。接触会把压力传到周围砂粒，让颈口两侧也向内补砂；没有「一格只能站一粒砂」的占位规则。穿透修正和真实速度分开，避免修正位置时制造弹跳。整堆落定后停止计算，倾斜或摇晃会重新唤醒。

物理内核是本地 WebAssembly，运行在 Worker 中；Canvas 2D 分批绘制细砂和由实际速度产生的短拖影。所有资源随站点提供，没有远程字体、账号或统计服务。设置里可以查看帧率和物理步耗时。

少量砂停在窄口时，可以轻轻摇晃或改变倾角，让它继续流动。

这是供把玩的颗粒模拟，**不是精确计时器**。流完所需时间随姿态、砂堆和设备负载变化。简化的颗粒接触与摩擦不能代表所有真实砂材；固定步长、角度测量方法和性能结果见 [验证记录](docs/VALIDATION.md)。

## 在本地运行

需要 Node.js 22.12+（推荐 24）：

```sh
npm ci
npm run dev
```

打开终端显示的地址即可。手机通过普通局域网 HTTP 地址打开时，通常只能拖动；运动传感器需要 HTTPS。

```sh
npm test             # 物理与坐标变换检查
npm run build        # 生成 dist
npm run benchmark    # 完整细砂流动、静止、堆角与耗时（需要稍等）
npm run test:browser # 先启动开发服务器；默认使用 /usr/bin/google-chrome
```

浏览器检查可通过 `CHROME_PATH` 指定 Chromium，通过 `BASE_URL` 检查其他地址。

修改 `native/sand.cpp` 后，需要安装 LLVM 的 `clang++`、`lld`，再运行：

```sh
npm run build:physics
npm test
npm run build
```

仓库自带编译好的 `src/sand.wasm`，直接运行页面不需要安装编译器。GitHub Actions 会从源码重新编译并测试。

## 自动发布

PR 会运行物理内核编译、测试和构建；合并或推送到 `main` 后，GitHub Actions 才会自动部署到 GitHub Pages。工作流位于 [deploy-pages.yml](.github/workflows/deploy-pages.yml)。Fork 后，在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**，再推送或手动运行工作流；站点子路径会自动配置。
